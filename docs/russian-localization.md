# Русский перевод

Версия `0.1.0-alpha.2` добавляет русский перевод игрового интерфейса IC2 для Minecraft 26.3 / Fabric. Язык выбирается стандартно: **Настройки → Язык → Русский**. В указанном пользователем профиле уже установлен `ru_ru`.

В `assets/ic2/lang/ru_ru.json` входит 1691 запись:

- 1291 перевод существующих ключей: предметы, блоки, машины, жидкости, культуры, достижения, субтитры, управление, подсказки и состояния.
- 127 дополнительных ключей для надписей, ранее записанных прямо в коде, атрибутов культур, недостающих подписей улучшений и названия недействительных семян.
- 273 названия предметов-блоков. В версии 26.3 их имена в инвентаре используют префикс `item`, поэтому одного перевода имени блока было недостаточно. Соответствующие записи добавлены и для английского языка.

Названия сверены с русской локализацией из предоставленного оригинального `industrialcraft-2-2.8.222-ex112.jar`, `assets/ic2/lang_ic2/ru_ru.properties` (в файле указана дата перевода 30.04.2019). Для новых механик перевод дополнен. Сохранены привычные термины: «Дробитель», «Экстрактор», «Электропила», «Энергохранитель», «Лазуротроновый кристалл». Единицы и технические сокращения EU, HU, kU, mB, NBT, MFE/MFSU/CESU сохранены.

Атрибуты растений переводятся только при отображении; их внутренние имена для селекции и сохранений остаются прежними. Сообщения инструментов и режимов передаются клиенту как компоненты перевода, включая вложенные параметры, чтобы язык выделенного сервера не подменял выбранный язык игрока.

## Проверка

Статическая проверка сравнивает полный набор английских и русских ключей, форматные подстановки, цветовые коды и содержимое ресурсов в готовом JAR:

```powershell
python .\scripts\validate_localization.py `
  --jar .\build\libs\ic2-fabric-26.3-0.1.0-alpha.2.jar `
  --output .\build\localization\validation-packaged.json
```

Проверка клиента действительно переключает Minecraft на `ru_ru` с перезагрузкой ресурсов. Она проверяет русские подписи, наличие всех 66 букв русского алфавита, имена всех зарегистрированных предметов IC2, передачу сообщений от сервера и интерфейсы машин. Все тестовые миры находятся внутри `build`.

```powershell
& .\tools\gradle-local.ps1 `
  -PenableGameTests=true `
  -PenableClientGameTests=true `
  -PprofileModsDir=build/profile-compat/mods `
  -PclientTestLanguage=ru_ru `
  build runClientGameTest
```

Итоговые проверки прошли:

- 442 серверных игровых теста и 10 модульных тестов — без ошибок (`build/verification-ru-alpha2-final.log`, `build/reports/gametest/results-ru-alpha2-final.xml`). После этого добавлена только недостающая строка `ic2.crop.invalid`; Java-код не менялся.
- Русский клиент с 11 модами профиля — успешно (`build/verification-ru-alpha2-client-final.log`). Проверены 12 конкретных переводов, 522 названия предметов, 66 русских букв, четыре настоящих сообщения по сети и интерфейсы генератора, дробителя и формовщика металла, включая нажатие кнопки режима.
- Все 1691 ключ совпадают с английским набором, параметры и цветовые коды сохранены. Оба языковых файла в готовом JAR совпадают с исходными (`build/localization/validation-packaged.json`).
- В архиве 1293 класса Java 25; они совпадают с проверенными классами сборки. Лицензия включена, тестовые классы отсутствуют (`build/artifact-audit-ru-alpha2.json`).

Отчёт клиента и семь снимков сохранены в `build/client-render-ru-alpha2/`. Галерея предметов и интерфейс формовщика дополнительно просмотрены визуально: кириллица читается, названия и подсказка режима помещаются в интерфейсе.

Готовая сборка: `ic2-fabric-26.3-0.1.0-alpha.2.jar`, SHA-256 `f704e5e6f775b8dc24ee20816fc17e3ce21fba2a639150953c9bf2a56cbb6449`. Предыдущая установленная сборка сохраняется отдельно от папки `mods` при обновлении.
