# IndustrialCraft 2 — Fabric 26.3: 0.1.0-alpha.12

Неофициальная alpha-версия переноса механик IndustrialCraft 2 Experimental на Minecraft Java **26.3** и **Fabric**. Требуются **Java 25**, **Fabric Loader 0.19.5 или новее** и Fabric API для 26.3; проверено с **0.164.0+26.3**.

## Что изменилось

- Исправлено дрожание текстуры заполнения индикаторов машин через общий метод отрисовки. Рабочие циклы дробителя и формовщика, пауза без энергии и завершение проверены в клиенте.
- Исправлена радиация: периодический урон проходит через нативные тики эффекта с исходным целочисленным расчётом дозы.
- Включены предыдущие исправления защиты Nano/Quantum, книги рецептов и автозаполнения крафтов, буров, древесного топлива и достижений. Русский перевод и использование ванильной меди сохранены.

## Установка

Установите рабочий файл **`ic2-fabric-26.3-0.1.0-alpha.12.jar`** в папку `mods` профиля Fabric 26.3. При обновлении замените прежний JAR IC2. Архив `-sources.jar` предназначен для исходников и не устанавливается как мод. Перед обновлением alpha-версии сделайте резервную копию мира.

Размер рабочего JAR: **8 179 445 байт**.

## Проверки и ограничения

Прошли **507 серверных GameTests и 10 JUnit-тестов**, затем отдельный повторный прогон русского клиента с 11 модами проверяемого профиля. В первом клиентском прогоне новая проверка ошибочно отклонила штатный порядок пакетов при завершении рецепта; уточнялся только тест, рабочий код не менялся. Это подтверждает выполненные сценарии, а не полную совместимость с любым модпаком или все особенности оригинального IC2. Интеграции JEI/AE2 из исходной базы в эту сборку не включены.
