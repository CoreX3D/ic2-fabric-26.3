# IndustrialCraft 2 — Fabric 26.3

Неофициальный перенос механик **IndustrialCraft 2 Experimental** на **Minecraft Java 26.3 и Fabric**. Электрические машины, переработка ресурсов, энергетическая сеть EU, ядерные реакторы, инструменты и броня IC2 — с русским переводом и адаптацией ресурсов к современному Minecraft.

Текущая версия: **0.1.0-alpha.12**. Проект находится в стадии alpha; полное совпадение со всеми особенностями оригинального IC2 пока не подтверждено.

**[Скачать мод](https://github.com/CoreX3D/ic2-fabric-26.3/releases)** · **[Изменения](CHANGELOG.md)** · **[Сообщить об ошибке](https://github.com/CoreX3D/ic2-fabric-26.3/issues)**

## Установка

| Компонент | Версия |
|---|---|
| Minecraft Java Edition | **26.3** |
| Java | **25** |
| Fabric Loader | **0.19.5 или новее** |
| Fabric API | Проверено с **0.164.0+26.3** |

1. Установите Fabric для Minecraft 26.3 и соответствующий Fabric API.
2. Скачайте из [Releases](https://github.com/CoreX3D/ic2-fabric-26.3/releases) файл `ic2-fabric-26.3-0.1.0-alpha.12.jar`.
3. Поместите его в папку `mods` нужного профиля. При обновлении замените прежний JAR IC2: в папке должна остаться одна версия мода.
4. Запустите игру. Для русского перевода выберите язык «Русский» в настройках Minecraft.

Архив `-sources.jar` предназначен для изучения исходников; устанавливать его в `mods` не нужно. Перед обновлением alpha-версии сохраните резервную копию мира.

## Возможности и адаптация

- Машины и производственные цепочки IC2: генераторы, дробитель, электрическая печь, формовщик металла, переработка жидкостей и другие устройства.
- Энергетическая сеть EU, провода, накопители и ядерные реакторы.
- Электроинструменты, реактивные ранцы, нановолоконная и квантовая броня.
- Ванильная медь используется вместо отдельной дублирующей меди мода. В цепочки переработки включены современные сырые медь, железо и золото; олово, свинец, уран и другие необходимые материалы IC2 сохранены.
- Выбранный баланс добычи сохраняет ванильную «Удачу»: сырая медь, железо и золото перерабатываются в два дроблёных ресурса, слитки — в одну пыль.
- Все **449 обычных рецептов крафта и переплавки** имеют условия открытия для зелёной книги рецептов, включая прежде скрытые варианты. Машинные процессы сохраняют собственные интерфейсы.
- Русский перевод: **1691 запись**, проверены названия всех **522 зарегистрированных предметов** IC2.

## Что исправлено в alpha.12

Общий метод отрисовки сохраняет дробную геометрию индикаторов: текстура внутри шкалы обработки больше не сжимается и не перескакивает при заполнении. Работающие циклы проверены на дробителе и формовщике металла. Скорость обработки и расход EU не изменены.

Радиация наносит периодический урон через нативные тики эффектов Minecraft; сохранён исходный расчёт величины дозы с целочисленным делением. В сборку также входят предыдущие исправления энергетической защиты брони, книги рецептов, работы буров, древесного топлива и фона достижений. Полный заряженный нановолоконный комплект поглощает **90% обычного урона**, расходуя EU.

Подробнее: [история изменений](CHANGELOG.md), [индикаторы машин](docs/progress-animation.md), [радиация](docs/radiation-effect.md), [электрическая броня](docs/electric-armor.md), [книга рецептов](docs/recipe-book.md).

## Проверки и ограничения

Для alpha.12 прошли **507 серверных GameTests и 10 JUnit-тестов**. Отдельный повторный прогон в русском игровом клиенте прошёл с 11 модами проверяемого профиля. После первого прогона уточнялась только новая проверка порядка пакетов при завершении рецепта; рабочий код мода не менялся.

Клиентская проверка включает реальные циклы двух машин, остановку без энергии и продолжение работы, геометрию и текстуры шкал, синхронизацию здоровья и EU, радиацию, автозаполнение крафтов и другие проверяемые пути. Это подтверждает выполненные сценарии, а не совместимость с любыми модпаками, шейдерами или каждым поведением оригинального IC2. Внешние интеграции JEI/AE2 из исходной базы в эту сборку не включены.

Запись проверок и их границы: [docs/verification.md](docs/verification.md).

## Сборка из исходников

Требуется **JDK 25**. Gradle Wrapper закреплён на **Gradle 9.6.0**; при первой сборке нужен доступ к сети для загрузки Gradle и зависимостей.

Linux/macOS:

```sh
./gradlew build
```

Windows PowerShell:

```powershell
.\gradlew.bat build
```

Готовые JAR находятся в `build/libs/`. Версии Minecraft, Loader, Fabric API и Loom закреплены в `gradle.properties`. Тестовые классы не включаются в рабочий JAR.

Дополнительные игровые проверки запускаются отдельно:

```sh
./gradlew -PenableGameTests=true runGameTest
./gradlew -PenableGameTests=true -PenableClientGameTests=true runClientGameTest
```

Клиентским проверкам нужны доступный графический сеанс и совместимое окружение. Приведённые команды сами по себе не устанавливают 11 модов из проверяемого профиля.

## Авторы и происхождение

IndustrialCraft 2 создан **IC2 Dev Team**. База этого переноса — [BilibiliXiaoYun/IC2R-fabric](https://github.com/BilibiliXiaoYun/IC2R-fabric), commit `5233264b7e0ad30a3ef71206c74fc43f252bc012`, производная от [IC2R](https://github.com/neo-industrial-mc/IC2R) с авторами и участниками, включая **HalfCooler**.

Upstream описывает свою базу как IC2 `2.9.40-ex119` с переносом недостающих возможностей из `2.8.222-ex112`. Оригинальный `2.8.222-ex112` использовался как поведенческий ориентир; этот проект не является его неизменённым исходным кодом. `ic2-reborn-0.1.5-alpha.jar` изучался для сравнения и не является исходной базой.

Официальные ресурсы IC2: [industrial-craft.net](https://industrial-craft.net/) и [форум IndustrialCraft](https://forum.industrial-craft.net/).
